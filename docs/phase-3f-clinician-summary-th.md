# Phase 3F Clinician Summary

Phase 3F เพิ่มขั้นตอนอนุมัติใบสั่งซื้อของห้องยา ก่อนรับของเข้า stock

## สิ่งที่เพิ่ม

- PO มี approval status แยกจากสถานะรับของ
- ส่ง PO เพื่อขออนุมัติได้
- อนุมัติ PO ได้
- ไม่อนุมัติ PO พร้อมบันทึกเหตุผลได้
- ระบบไม่ให้รับของจาก PO ที่ยังไม่ approved
- หน้า Prescriptions แสดงปุ่มส่งอนุมัติ/อนุมัติ/ไม่อนุมัติ/รับของจาก PO ตามสถานะ

## ประโยชน์ในการใช้งาน

- ลดการรับยาเข้า stock โดยไม่มีการอนุมัติ
- เห็นประวัติว่าใครส่ง ใครอนุมัติ หรือใครไม่อนุมัติ
- เตรียมต่อยอดเป็นวงเงินอนุมัติหรือหลายผู้อนุมัติได้

## ข้อจำกัดตอนนี้

- ยังไม่มี approval threshold ตามยอดเงิน
- ยังไม่มีหลายลำดับผู้อนุมัติ
- ยังไม่ผูกงบประมาณแผนก
- ยังไม่เชื่อมบัญชีเจ้าหนี้ supplier
