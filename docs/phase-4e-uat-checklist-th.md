# Phase 4E UAT Checklist: Label Template Management

## Template Setup

- [ ] สร้าง template แบบ item ได้
- [ ] สร้าง template แบบ lot ได้
- [ ] กำหนด fields เช่น `title,barcode,detail` ได้
- [ ] กำหนด header/footer ได้
- [ ] ตั้ง default ต่อ template type ได้

## Export

- [ ] เลือก label template ใน scanner panel ได้
- [ ] export ZPL โดยใช้ template ได้
- [ ] export ESC/POS โดยใช้ template ได้
- [ ] print job เก็บ `label_template_id`
- [ ] ถ้าไม่เลือก template ยังใช้ default format เดิมได้

## Sign-Off

- [ ] ห้องยายืนยัน field ที่ต้องการบน item label
- [ ] ห้องยายืนยัน field ที่ต้องการบน lot label
- [ ] ทีม IT ระบุขนาด label จริงที่จะใช้กับ printer
