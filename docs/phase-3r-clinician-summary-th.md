# สรุปสำหรับคลินิก: Phase 3R ทะเบียนยาควบคุม

Phase 3R เพิ่มทะเบียนยาควบคุมสำหรับห้องยา เพื่อให้เจ้าของคลินิกหรือหัวหน้าห้องยาตรวจดูรายการรับเข้า จ่ายออก และโอนยาของรายการที่ถูกระบุว่าเป็นยาควบคุมได้ง่ายขึ้น

## สิ่งที่เพิ่ม

- Inventory item ระบุได้ว่าเป็น controlled substance
- ระบุ schedule/category ของยาควบคุมได้
- รายงาน controlled substances ดูได้ตามช่วงวันที่
- CSV export สำหรับเก็บประกอบการตรวจทาน
- Operations dashboard แสดงยอด item ควบคุม จำนวน event และ event ล่าสุด

## ข้อมูลที่รายงานรวม

- การรับ lot เข้าคลัง
- การจ่ายยาจาก prescription
- การโอนยาระหว่าง location/bin

## ประโยชน์กับคลินิก

- เห็นประวัติการเคลื่อนไหวของยาควบคุมในที่เดียว
- ลดเวลารวบรวมข้อมูลเวลาตรวจทานสต็อก
- วางฐานสำหรับ witness/co-sign หรือรายงานตามกฎหมายในเฟสต่อไป
