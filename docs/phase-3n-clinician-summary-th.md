# สรุปสำหรับคลินิก: Phase 3N ระบบย้ายสต็อกแบบมีอนุมัติ

Phase 3N เพิ่ม workflow การย้ายสต็อกระหว่าง location/bin ให้เหมาะกับงานหน้าคลินิกและห้องยา โดยเฉพาะกรณีที่ต้องมีคนขอ คนอนุมัติ และคนรับเข้าปลายทาง

## สิ่งที่ใช้ได้แล้ว

- ขอ “ย้าย stock” แบบเดิมได้ทันที ถ้าไม่ต้องอนุมัติ
- เลือก lot ที่ต้องการย้ายได้
- ติ๊ก `Approval required` เพื่อสร้างคำขอย้ายเป็นสถานะ `pending`
- กดอนุมัติคำขอย้ายเพื่อเปลี่ยนเป็น `in_transit`
- กดรับเข้าปลายทางเพื่อปิดงานเป็น `completed`
- ยกเลิกคำขอที่ยัง pending หรือ in transit ได้ พร้อมบันทึกเหตุผล

## ผลต่อสต็อก

- คำขอ `pending` ยังไม่ตัด stock จากต้นทาง
- เมื่ออนุมัติ ระบบตัด stock จาก location/bin ต้นทาง
- เมื่อรับเข้าปลายทาง ระบบเพิ่ม stock ที่ location/bin ปลายทาง
- ถ้ายกเลิกหลังอนุมัติแล้ว ระบบคืน stock กลับต้นทาง

## ประโยชน์กับคลินิก

- ลดความสับสนระหว่าง “ขอย้าย”, “กำลังย้าย”, และ “รับของแล้ว”
- ตรวจสอบย้อนหลังได้ว่าใครขอ ใครอนุมัติ ใครรับ และใครยกเลิก
- รองรับงานห้องยา/คลัง/จุดจ่ายยาที่มีหลาย location มากขึ้น

## ข้อควรตรวจใน UAT

- ชื่อ location/bin ต้องสื่อสารตรงกับพื้นที่จริงในคลินิก
- ผู้ใช้ต้องเข้าใจว่า pending ยังไม่ตัด stock
- ขั้นตอนรับเข้าปลายทางต้องมีเจ้าหน้าที่รับผิดชอบชัดเจน
