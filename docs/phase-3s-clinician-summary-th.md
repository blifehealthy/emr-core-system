# สรุปสำหรับคลินิก: Phase 3S พยานรับรองการจ่ายยาควบคุม

Phase 3S เพิ่มขั้น witness สำหรับการจ่ายยาควบคุม เมื่อ inventory item ถูกตั้งว่าเป็น controlled substance ระบบจะบังคับให้กรอกผู้ witness ก่อนบันทึกการจ่ายยา

## สิ่งที่เปลี่ยน

- จ่ายยาทั่วไปยังทำงานเหมือนเดิม
- จ่ายยาควบคุมต้องมี `witnessUserId`
- คนจ่ายยาและ witness ต้องเป็นคนละ user
- ระบบบันทึกเวลาที่ witness และบันทึกข้อความประกอบได้
- ทะเบียนยาควบคุมจะแสดงข้อมูล witness สำหรับ dispense event

## ประโยชน์กับคลินิก

- เพิ่มการตรวจทานสองคนสำหรับยาควบคุม
- ทำให้ทะเบียนยาควบคุมมีหลักฐานมากขึ้น
- เป็นฐานสำหรับ digital signature หรือ re-authentication ในเฟสถัดไป
