# สรุป Phase 3K สำหรับทีมคลินิก: โปรไฟล์เครื่องพิมพ์ฉลาก

Phase 3K เพิ่มฐานสำหรับตั้งค่าเครื่องพิมพ์ฉลากยา/คลังยาในระบบ โดยยังคงใช้หน้าคลังยาเดิมเป็นจุดทำงานหลัก

## สิ่งที่เพิ่ม

- ตั้งค่า printer profile ได้ตามคลินิก
- ระบุภาษาฉลาก เช่น ZPL, ESC/POS, หรือ HTML
- ระบุรูปแบบการส่งงานพิมพ์ เช่น เปิดใน browser, ส่งผ่าน network, หรือส่งผ่าน utility bridge
- เลือก profile ตอน export ฉลาก barcode
- ระบบเก็บประวัติงานพิมพ์ว่าผูกกับ printer profile ใด และสถานะเป็น exported หรือ queued

## ประโยชน์

- ทีมยาเริ่มแยกเครื่องพิมพ์ฉลากตามจุดใช้งานได้
- IT เห็น endpoint/connection ที่ตั้งไว้ต่อ profile
- ประวัติงานพิมพ์ตรวจสอบย้อนหลังได้ดีขึ้น
- เปิดทางต่อยอดไปสู่ printer bridge หรือ network printer จริงในเฟสถัดไป

## หมายเหตุ

เฟสนี้ยังไม่ใช่ตัวส่งงานพิมพ์เข้า driver โดยตรง แต่เป็น foundation ที่ทำให้ระบบรู้จักเครื่องพิมพ์และบันทึก routing ของงานพิมพ์ได้ก่อน
