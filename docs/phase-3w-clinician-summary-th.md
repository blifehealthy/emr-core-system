# สรุปสำหรับคลินิก: Phase 3W อนุมัติส่วนต่างยา controlled drug

Phase 3W เพิ่มขั้นตอน review/approval เมื่อรอบตรวจนับยา controlled drug มีส่วนต่าง

## สิ่งที่เปลี่ยน

- ถ้านับจริงตรงกับยอดในระบบ รอบจะปิดเป็น `closed` ทันที
- ถ้ามีส่วนต่าง รอบจะเปลี่ยนเป็น `pending_approval`
- admin หรือผู้มีสิทธิ์งานยาอนุมัติส่วนต่างได้พร้อม note
- ระบบเก็บผู้อนุมัติ เวลาอนุมัติ และหมายเหตุอนุมัติ
- หน้า Operations แสดง action สำหรับอนุมัติรอบที่รอ approval

## ประโยชน์กับคลินิก

- ลดความเสี่ยงจากการปิดรอบ controlled drug ที่มีส่วนต่างโดยไม่มี review
- ทำให้ pharmacy lead/owner เห็นเหตุผลและรับรองส่วนต่างในระบบ
- เป็นฐานสำหรับขั้นต่อไป เช่น บังคับคนอนุมัติคนละคน, witness, หรือ per-lot count
