# สรุปสำหรับคลินิก: Phase 3O FEFO และการกันจ่ายยาหมดอายุ

Phase 3O เพิ่มการป้องกันตอนเลือก lot ในห้องยา เพื่อช่วยให้เจ้าหน้าที่ใช้ยาที่หมดอายุก่อนก่อน และลดความเสี่ยงจากการหยิบ lot หมดอายุ

## สิ่งที่ระบบทำเพิ่ม

- ถ้าเลือก lot ที่หมดอายุ ระบบจะไม่ให้จ่าย/ย้าย เว้นแต่กรอกเหตุผล override
- ถ้ามี lot อื่นที่หมดอายุก่อนและมี stock พอ ระบบจะให้ใช้ lot นั้นก่อนตามหลัก FEFO
- ถ้าต้องเลือก lot ที่หมดอายุช้ากว่า ระบบต้องกรอกเหตุผล FEFO override
- ระบบบันทึกเหตุผล override และ lot ที่ระบบแนะนำไว้ให้ตรวจย้อนหลัง

## ใช้กับ workflow ไหน

- การจ่ายยาจากใบสั่งยา
- การสร้างคำขอย้าย stock หรือย้าย stock ทันทีระหว่าง location/bin

## ประโยชน์กับคลินิก

- ลดโอกาสใช้ยาหมดอายุ
- ลดของเสียจากการไม่ใช้ lot ที่ใกล้หมดอายุก่อน
- มีหลักฐานเหตุผลเมื่อมีกรณีจำเป็นต้อง override

## จุดที่ควรตกลงก่อน UAT

- ใครมีสิทธิ์กรอกเหตุผล override
- ข้อความเหตุผล override ควรละเอียดระดับไหน
- ต้อง review override รายวันหรือรายสัปดาห์หรือไม่
