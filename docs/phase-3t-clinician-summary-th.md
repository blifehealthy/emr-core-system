# สรุปสำหรับคลินิก: Phase 3T ยืนยันตัวตนพยานจ่ายยาควบคุม

Phase 3T ทำให้ขั้น witness ของยาควบคุมแน่นขึ้น จากเดิมที่กรอก user id ของพยาน เป็นการให้พยานยืนยันตัวตนซ้ำด้วย login code ก่อนบันทึกการจ่ายยา

## สิ่งที่เปลี่ยน

- จ่ายยาทั่วไปยังทำงานเหมือนเดิม
- จ่ายยาควบคุมต้องมี witness user และ witness login code
- witness ต้องเป็น user ที่ active และอยู่คลินิกเดียวกัน
- ระบบไม่เก็บ login code ดิบลงฐานข้อมูล
- ระบบบันทึกวิธียืนยันตัวตน เวลา re-auth และ signature hash สำหรับ audit
- ทะเบียนยาควบคุมมี metadata ของการยืนยันพยานใน dispense event

## ประโยชน์กับคลินิก

- ลดโอกาสกรอกชื่อพยานแทนกันโดยไม่มีการยืนยัน
- เพิ่มหลักฐานตรวจสอบย้อนหลังสำหรับยาควบคุม
- เป็นฐานก่อนต่อยอดไปสู่ per-user password, MFA, หรือ digital signature ภายนอก
