# สรุป Phase 3M สำหรับทีมคลินิก: ยอดคงเหลือต่อ Location และการย้าย Stock

Phase 3M ต่อยอดจาก location/bin ใน Phase 3L ให้เริ่มเห็นยอดคงเหลือตามจุดเก็บจริง และย้าย stock ระหว่างจุดได้

## สิ่งที่เพิ่ม

- ตารางยอดคงเหลือต่อ item/location/bin
- รับเข้า lot แล้วเพิ่มยอดของ location ที่เลือก
- ปรับ stock แล้วเพิ่ม/ลดยอดของ location ที่เลือก
- จ่ายยาแล้วลดยอดของ location ที่เลือก
- ย้าย stock จาก location หนึ่งไปอีก location หนึ่ง
- บันทึกประวัติ transfer และ stock movement audit

## ประโยชน์

- ทีมยาเห็นว่ายาคงเหลืออยู่จุดไหน
- ลดความสับสนระหว่างห้องยาใหญ่ จุดจ่ายยา และชั้นวาง
- ตรวจย้อนหลังได้ว่าย้าย stock จากไหนไปไหน

## หมายเหตุ

เฟสนี้เป็น immediate transfer คือกดย้ายแล้วถือว่าย้ายสำเร็จทันที ยังไม่มีสถานะ pending/in-transit หรือ approval workflow
