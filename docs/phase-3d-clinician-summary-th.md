# Phase 3D สรุปสำหรับแพทย์และเภสัช

Phase 3D เพิ่มการคุม stock ยาระดับ lot และวันหมดอายุ เพื่อให้ flow ห้องยา
ใกล้การใช้งานจริงมากขึ้นหลังจาก Phase 3C มี inventory และการจ่ายยาแล้ว

## สิ่งที่ใช้งานได้

- รับยาเข้าคลังเป็น lot ได้
- ระบุ lot number ได้
- ระบุวันหมดอายุได้
- ระบุ supplier และเลขอ้างอิงการรับเข้าได้
- ดูรายการ lot ของยาในหน้า Prescriptions ได้
- เห็น lot ที่ใกล้หมดอายุ
- จ่ายยาจาก prescription โดยระบุ lot ได้
- เมื่อจ่ายยาจาก lot ระบบลดทั้ง stock รวมของยาและ stock ของ lot นั้น
- stock movement เก็บ audit ว่า movement นั้นเกี่ยวกับ lot ใด

## Flow ที่ควรทดสอบ

1. สร้าง inventory item ของยา
2. รับยาเข้าคลังเป็น lot พร้อมวันหมดอายุ
3. ตรวจว่า stock รวมเพิ่มขึ้น
4. เปิด prescription ของผู้ป่วย
5. จ่ายยาโดยเลือก lot
6. ตรวจว่า stock รวมและ stock ของ lot ลดลง
7. ดู stock movement ว่ามี lot id ติดมาด้วย

## ข้อจำกัดที่ยังไม่ใช่ scope นี้

- ยังไม่มี barcode scan
- ยังไม่มีแยก stock หลายสาขาหรือหลายห้องเก็บยา
- ยังไม่มี purchase order approval
- ยังไม่มีทะเบียนยาควบคุมพิเศษ
- ยังไม่มี supplier master แบบเต็ม
