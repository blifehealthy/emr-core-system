# สรุปสำหรับคลินิก: Phase 3P รายงานตรวจทาน Override ห้องยา

Phase 3P เพิ่มรายงานสำหรับดูเหตุการณ์ที่เจ้าหน้าที่ override กฎ FEFO หรือ lot หมดอายุ เพื่อให้หัวหน้าห้องยาและเจ้าของคลินิกตรวจทานย้อนหลังได้ง่ายขึ้น

## สิ่งที่ดูได้

- จำนวน override ทั้งหมดในช่วงวันที่เลือก
- แยกจำนวน dispense override และ transfer override
- แยก expiry override และ FEFO override
- รายการยาที่มี override มากที่สุด
- เหตุการณ์ล่าสุดพร้อม lot ที่เลือก เหตุผล และ lot ที่ระบบแนะนำ

## ใช้งานตรงไหน

- Operations dashboard จะโหลด pharmacy override report ตามช่วงวันที่เดียวกับ daily operations
- API มี CSV สำหรับเอาไป review หรือเก็บเป็นหลักฐาน

## ประโยชน์กับคลินิก

- เห็น pattern ว่ามีการ override บ่อยกับยาใด
- ใช้ตรวจสอบว่าเหตุผล override เหมาะสมหรือไม่
- ช่วยตัดสินใจว่าจะต้องแยกสิทธิ์ override หรือเพิ่มขั้นอนุมัติในเฟสถัดไป
