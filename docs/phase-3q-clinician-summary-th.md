# สรุปสำหรับคลินิก: Phase 3Q แยกสิทธิ์งานเสี่ยงในห้องยา

Phase 3Q ทำให้สิทธิ์ของงานห้องยาที่มีความเสี่ยงสูงแยกชัดขึ้น โดยเฉพาะการ override กฎ FEFO/วันหมดอายุ และการอนุมัติ/รับ/ยกเลิกการโอนยาระหว่างจุดเก็บ

## สิ่งที่เปลี่ยน

- การจ่ายยาปกติยังทำได้ตามสิทธิ์เดิมของผู้สั่งจ่าย
- ถ้ามีเหตุผล override FEFO หรือยาหมดอายุ ต้องเป็นสิทธิ์ admin
- การอนุมัติโอนยาเป็นสิทธิ์ admin
- การรับยาเข้าปลายทางทำได้โดย nurse หรือ admin
- การยกเลิกใบโอนยาเป็นสิทธิ์ admin

## ประโยชน์กับคลินิก

- ลดโอกาสที่เจ้าหน้าที่ทั่วไป override lot ยาหรือวันหมดอายุโดยไม่ผ่านผู้รับผิดชอบ
- ให้เจ้าหน้าที่พยาบาล/ห้องยารับยาที่มาถึงปลายทางได้โดยไม่ต้องให้ admin ทำทุกขั้น
- ตรวจสอบย้อนหลังง่ายขึ้น เพราะเหตุผล override ยังถูกเก็บใน dispense/transfer audit เหมือนเดิม

## จุดที่ควรตกลงก่อนใช้งานจริง

- ใครในคลินิกควรถือ role admin สำหรับห้องยา
- การรับ transfer ที่ปลายทางควรเป็นหน้าที่ nurse หรือ admin ในแต่ละสาขา
- ถ้า override เกิดบ่อย ควรใช้รายงาน Phase 3P review เป็นรายวันหรือรายสัปดาห์
