# สรุปสำหรับคลินิก: Phase 3X แยกคนปิดรอบกับคนอนุมัติส่วนต่าง

Phase 3X เพิ่มกติกาว่า controlled-drug reconciliation ที่มีส่วนต่าง ต้องให้คนละคนกับผู้ปิดรอบเป็นผู้อนุมัติ

## สิ่งที่เปลี่ยน

- คนที่ปิดรอบตรวจนับและทำให้เกิด `pending_approval` อนุมัติรอบนั้นเองไม่ได้
- ผู้อนุมัติต้องเป็น user อื่นที่มีสิทธิ์งานยา
- ระบบใช้ user จาก session/actor ที่ล็อกอิน ไม่เชื่อ `approvedByUserId` ที่ส่งมาใน body
- มี database constraint กันข้อมูล approver/closer เป็นคนเดียวกัน
- ถ้าพยายามอนุมัติเอง ระบบตอบ conflict พร้อมข้อความชัดเจน

## ประโยชน์กับคลินิก

- ลดความเสี่ยงจากการบันทึกส่วนต่าง controlled drug โดยไม่มีคนทวน
- ทำให้ review ของ pharmacy lead/owner มีหลักฐานแยกจากผู้ปิดรอบ
- เป็นฐานสำหรับขั้นต่อไป เช่น witness re-auth หรือ approval routing หลายชั้น
