# Phase 5 Planning Seeds

Phase 5 should start only after pilot UAT/go-no-go produces real findings.
This file lists candidate tracks so new requests can be captured without
disturbing pilot stabilization.

## Candidate Tracks

### Patient Communication

- appointment reminders
- prescription instruction delivery
- LINE/SMS integration
- consent-aware messaging rules
- message audit trail

### External Integrations

- accounting export
- payer/insurance claim export
- lab order/result integration
- external identity provider production rollout
- printer vendor bridge packaging

### Clinical Depth

- lab result module
- procedure notes
- problem-list enhancements
- clinical decision support improvements
- structured templates by specialty

### Pharmacy And Inventory Depth

- supplier payment handoff
- controlled drug regulatory export
- automated reorder suggestions
- multi-branch stock visibility
- hardware certification matrix

### Analytics And Operations

- trend dashboards
- utilization reports
- revenue/stock variance dashboards
- clinical quality indicators
- alert integration with monitoring tools

### Security And Compliance

- PDPA retention policy tooling
- record export package
- stricter audit review dashboard
- session/device management
- backup status ingestion

## Recommended Rule

Only promote a Phase 5 item when it has:

- named business owner
- concrete workflow or regulatory need
- expected pilot/production benefit
- acceptable fallback
- clear UAT criteria
